# Manual de primeros días · Vértice Restaurant

Sitio estático (GitHub Pages) con el manual de usuario para los primeros días con Vértice Restaurant: del garzón que comanda a la caja que cobra y cierra el día, con las pantallas reales del sistema (datos de la demo ficticia «Gran Dragón Dorado»).

- `index.html`: el sitio, con buscador rápido (Ctrl+K o /).
- `Manual-primeros-dias-Vertice-Restaurant.pdf`: la versión para imprimir.
